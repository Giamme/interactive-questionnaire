Anyone the page can't save for, including visitors without a Claude account, can send their answers as a message with «Send your answers»; the owner pastes it into «Add answers sent as a message» and the answers join the team's under the sender's name. The code in the message is letters and digits only, with a checksum, so it survives the formatting chat apps and mail clients apply, and a damaged code is refused rather than read wrong.
