Anyone the page can't save for, including visitors without a Claude account, can send their answers with «Send your answers», which makes a one-line code to paste into a message; the owner pastes it into «Add answers sent as a message» and the answers join the team's under the sender's name. The code is letters and digits only, with a checksum, so it survives the formatting chat apps and mail clients apply, and a damaged code is refused rather than read wrong.
